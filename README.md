# ETF Comparison Dashboard

Vercel 배포 가능한 Next.js 프로젝트입니다.

## 중요

압축을 풀었을 때 저장소 루트에 바로 아래 파일/폴더가 있어야 합니다.

- package.json
- app/
- tsconfig.json
- next.config.ts

이전 소스에 있던 `return settled.map(...)` 코드는 제거되어 있습니다.

## 실행

```bash
npm install
npm run build
npm run dev
```

## GitHub 반영

기존 저장소 파일을 전부 삭제하거나 덮어쓴 뒤 업로드하세요.

```bash
git add .
git commit -m "replace with vercel ready next app"
git push
```
